# Copy Link on Click Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clicking a `http`/`https`/`mailto` link copies its destination to the clipboard and shows a `link copied` status chip instead of doing nothing.

**Architecture:** `justify::paint_frag` keeps the click handling and gains a small `click_link(ctx, url)` that copies and leaves a one-frame flag in `ctx.data`. `App::ui` drains the flag and calls the existing `set_status`.

**Tech Stack:** Rust 2021, egui/eframe 0.36 (`Context::copy_text`, `Context::data_mut`). No new crates.

**Spec:** `docs/superpowers/specs/2026-11-22-copy-link-design.md`

## Global Constraints

- No new dependencies; do not enable `eframe`'s `links` feature.
- Only `http://`, `https://`, `mailto:` copy (`justify::link_is_safe`, case-insensitive).
- `#anchor` links keep jumping to the heading and never copy.
- Status text is exactly `link copied` and uses `STATUS_DURATION` (1.5 s).
- Link painting is shared by paragraphs, list items, quotes and table cells, so one change covers all of them.

## Review Focus

- Inert schemes (`javascript:`, `data:`, `file:`, relative paths) must not copy and must not raise the chip.
- A click that starts a selection drag over a link must not copy (only `Sense::click` counts).
- Table-cell and list-item links must copy too, because they go through the same `paint_frag`.
- `#anchor` clicks must still jump and must not also copy.
- Copied text must be the resolved URL, including reference-style links (`[text][ref]`).

mod copy {

    fn safe_links_copy_and_flag_the_status() {
        let ctx = egui::Context::default();
        assert!(click_link(&ctx, "https://example.com/docs"));

                .any(|c| matches!(c, egui::OutputCommand::CopyText(t) if t == "https://example.com/docs"))

        assert!(copied, "no CopyText command");

    fn inert_schemes_copy_nothing() {
        let ctx = egui::Context::default();

            assert!(!link_is_safe(url));
            assert!(!click_link(&ctx, url), "{url}");

        assert_eq!(commands, 0);
        let flagged = ctx
            .data_mut(|d| d.get_temp::<()>(egui::Id::new(LINK_COPIED)))
            .is_some();
        assert!(!flagged);
    }
}

- [ ] **Step 3: Implement the flag and helper**

In `src/justify.rs`, next to `link_is_safe`:

```rust
/// One-frame handoff: a link click asked for the `link copied` status chip.
pub(crate) const LINK_COPIED: &str = "jiaoren-link-copied";

/// Copy a safe link and leave the status flag. Inert schemes copy nothing.
fn click_link(ctx: &egui::Context, url: &str) -> bool {
    if !link_is_safe(url) {
        return false;
    }
    ctx.copy_text(url.to_owned());
    ctx.data_mut(|d| d.insert_temp(Id::new(LINK_COPIED), ()));
    true
}
```

In `paint_frag`, replace the `safe && response.clicked()` branch's `ui.ctx().open_url(...)` with `click_link(ui.ctx(), url);` (drop the now-unused `safe &&` guard, keep `let safe = link_is_safe(url);` for the cursor and hover).
